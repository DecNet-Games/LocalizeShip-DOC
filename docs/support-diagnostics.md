# Support & Diagnostics
{: .fs-9 }

### Redacted Environment & Workspace Diagnostics for Rapid Support
{: .fs-6 .text-grey-dk-000 }

---

When troubleshooting complex workspace configurations, provider integrations, or gate evaluation edge cases, LocalizeShip includes a built-in diagnostic exporter. It generates a clean, plain-text diagnostic summary designed to be shared with DecNet Games customer support without leaking confidential game narrative or dialogue text.

---

## How to Export Diagnostics

You can export diagnostics from the **Release Board**:

1. Open **Tools > Decnet > LocalizeShip > Release Board**.
2. In the bottom-left corner of the filter panel, click **Export Support Diagnostics**.
3. LocalizeShip compiles the report and saves it to a timestamped file in your project root:
   `LocalizeShip_Diagnostics_YYYYMMDD_HHMMSS.txt`
4. A popup dialog displays the exact disk location of the saved file.

---

## Strict Privacy & Redaction Rules

LocalizeShip is built local-first for commercial studios under non-disclosure agreements (NDAs). The diagnostic exporter enforces the following privacy rules:

* **Zero Story/Dialogue Leaks**: The diagnostic export **never** includes actual string table contents, source sentences, translated dialogue, character names, or voice audio filenames.
* **No Secret Credentials**: API keys, endpoint URLs, and user passwords are never stored in the workspace asset and are **never included** in diagnostic exports.
* **No Telemetry Uploads**: The diagnostic file is created locally on your hard drive. LocalizeShip **never silently uploads** or transmits diagnostic logs to any remote server.
* **Human Auditable**: The exported file is plain UTF-8 text. You can open and review the entire file in Notepad or VS Code before sharing it with customer support.

## Submitting a Support Ticket

If you encounter an issue or reproducible bug:

1. Generate your diagnostic report using the steps above.
2. If possible, note your reproduction steps and the relevant EditMode test output.
3. Open an issue on our official GitHub repository:
   [DecNet Games Support](https://github.com/DecNet-Games/LocalizeShip-DOC/issues)
4. Paste or attach your `LocalizeShip_Diagnostics_*.txt` file.
